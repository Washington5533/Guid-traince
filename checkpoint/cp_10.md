# cp_10 · MCP 工具层设计

> 状态：✅ 已实现  
> 实现文件：`guardian/mcp_server.py`（~1500 行）  
> CLI 入口：`run.py serve` / `run.py start` / `run.py watch --with-mcp`

## 设计目标

把 guardian 全部观测与操作能力暴露为标准 MCP (Model Context Protocol) 工具，供 Claude Code、OpenClaw 等外部 agent 客户端接入。

## 核心约束

1. **非阻塞** — MCP 包未安装 / 启动失败 / 运行时崩溃均不影响训练看护
2. **默认只读** — 写工具需显式开启 + 口令鉴权
3. **可事后补挂** — 训练已在进行时随时可启动 MCP 接入

## 传输方式

| 方式 | 命令 | 适用场景 |
|------|------|----------|
| stdio | `python run.py serve` | Claude Code 子进程接入 |
| SSE | `python run.py serve --transport sse` | 远程 SSH 隧道 |
| 同进程 | `python run.py watch --with-mcp` | 实时性最好（共享内存） |

## 工具分类（28 个）

### 只读（18 个）

- 训练监控：`get_training_status`, `get_metrics_history`, `get_anomaly_history`, `get_recovery_history`, `get_agent_decision_log`, `get_summary`
- 实验查询：`list_experiments`, `query_experiment`, `compare_experiments`
- Checkpoint：`list_checkpoints`, `compare_checkpoints`
- 模型与配置：`get_model_structure`, `get_guardian_mode`, `get_gallery_config`, `get_import_format`, `inspect_source`
- 契约：`get_contract_status`, `list_contract_proposals`

### 受限写（10 个）

- 训练控制：`trigger_recovery`, `restart_with_params`, `stop_training`, `trigger_full_validate`
- 契约管理：`approve_contract_proposal`, `reject_contract_proposal`
- 训练后：`run_visualization`, `set_gallery_config`, `run_inference`
- 数据导入：`submit_import`

## 安全层次

```
Layer 1: 读操作 → 无需鉴权，始终可用
Layer 2: 写操作 → enable_write_tools=true + write_token 匹配
Layer 3: 训练后写操作 → Layer 2 + training_active=false
Layer 4: 参数约束 → contract.yaml adjustable_paths 白名单
```

## 双模式架构

```
MCP 客户端连接 → on_client_connect() → advisor.set_delegated(True)
                                      → 模式切换为 MCP_DELEGATED
MCP 客户端断开 → on_client_disconnect() → advisor.set_delegated(False)
                                        → 恢复 STANDALONE
```

模式切换时，内置 agent 的决策权被让渡/恢复，确保同一时刻只有一方做决策。

## SDK 兼容

同时兼容 `mcp<2.0` 和 `mcp>=1.0`，通过运行时 import 探测选择正确的 SDK API：

```python
try:
    from mcp.server.mcpserver import MCPServer  # SDK v2
except ImportError:
    from mcp.server import Server as MCPServer   # SDK v1
```

## 幂等保证

`IdempotencyGuard` 类：相同 `request_id` 在 `dedup_window`（默认 300s）内的重复调用直接返回首次结果。write 类工具全部支持。

## 访问日志

所有工具调用记录到 `{log_dir}/mcp_access_log.json`，格式：

```json
{
  "tool": "restart_with_params",
  "client_id": null,
  "params": {"action": "reduce_batch", "param": 0.5},
  "success": true,
  "deduplicated": false,
  "timestamp": 1754303422
}
```

> `_token` 不记入日志。
