# cp_13 · 图片筛选与展示 (Gallery)

**文件**: `guardian/gallery.py`, `guardian/streamlit_app.py`
**阶段**: 训练后
**核心目标**: 自动从推理结果中筛选多套图集，无需逐张看图挑图

> **AI 决策边界**: Agent 创造性定义筛选策略 → 用户确认/NL修正 → 规则引擎执行。详情见下。

---

## 为什么需要

训练完以后，开发者需要：
- 挑几张好图放报告里（汇报精选）
- 找出模型搞不定的样本做分析（难样本）
- 找到模棱两可的边界案例（边界案例）

手动挑图耗时且主观。F3 让 agent 基于模型输出自动提议筛选策略，用户只需确认或用自然语言微调。

## 核心交互流

```
训练结束
  → guardian agent 推断任务类型（读模型代码或用户描述）
  → agent 提出多套筛选策略（name + rationale + filters）
  → 终端展示提案
  → 用户确认/修正:
      [回车] 确认执行
      "小目标改5%，加夜间场景" → agent 重新生成
      export → 导出 JSON
      cancel → 取消
  → 执行推理 + 筛选
  → 保存结果 + Streamlit 展示
```

## AI 决策边界

| 维度 | 边界 |
|------|------|
| **能做** | 读模型代码推断任务类型；定义筛选维度与阈值；组合多维度创建新策略；NL 解释每套图集设计意图 |
| **不能做** | 不经确认直接执行；修改标签；删除/覆盖训练数据 |
| **人把关** | 策略需确认后才执行（事后在 Streamlit 里也可随时调整） |
| **降级** | AI 不可用 → 3 套默认策略（top20/bottom20/类均衡），无 rationale |

## MCP 模式

- **Claude Code 连接时**: guardian agent 让位。Claude Code 可通过 `get_gallery_config` 读取当前配置，通过 `set_gallery_config` 更新策略并触发重新筛选
- **断开时**: guardian agent 恢复自主决策

## 关键类与方法

```
GalleryManager(config, advisor, ckpt_analyzer)
  - infer_task_type(model_fn_or_desc) → str
  - propose_strategies(task_type, metrics_context, user_feedback) → dict
  - execute(checkpoint_path, strategies, data_source) → dict
  - export_config(strategies, path) / load_config(path)
  - render_proposal(strategies) → str   # 终端展示
  - launch_streamlit(results, data_dir, port)

InferenceRunner (共享模块，见 cp_16)
  - detect_task_type / run / recommend_*
```

## 筛选过滤类型

| 类型 | 说明 |
|------|------|
| `confidence_range` | 置信度区间 [min, max] |
| `per_class_top` | 每类取 top-k 张 |
| `bbox_area_percentile` | bbox 面积百分位（仅检测） |
| `class_filter` | 指定类别 |
| `prediction_matches_label` | 预测与标签匹配/不匹配 |

## 默认策略（AI 不可用时）

1. **汇报精选**: confidence ∈ [0.9, 1.0] + per_class_top_k=5
2. **难样本**: confidence ∈ [0, 0.5]
3. **边界案例**: confidence ∈ [0.4, 0.7]
