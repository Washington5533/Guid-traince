# cp_14 · 跨实验查询 (ExperimentQuery)

**文件**: `guardian/experiment_query.py`
**阶段**: 跨实验（训练后）
**核心目标**: 自然语言查询历史实验记录，不用靠脑子记参数

> **AI 决策边界**: NL→结构化查询翻译（纯只读，无确认步骤）。风险极低。

---

## 为什么需要

每次训练产出一份 `summary_*.json`。几次实验之后，开发者想知道：
- "上次 mAP 最高的那次，lr 和 batch_size 是多少"
- "对比实验 #7 和 #12，为什么 #12 更好"
- "给我所有准确率 > 0.9 的实验"

这些信息分散在多个 JSON 文件里。F4 提供统一的 NL 查询入口。

## 核心架构

```
用户 NL 问题
  → AI 翻译为结构化查询 DSL（filters + sort + limit + fields）
  → 规则引擎在内存索引上执行
  → 格式化回答（自然语言 + JSON 结果）
```

查询 DSL：
```json
{"filters": [{"field": "字段", "op": "eq|gt|lt|gte|lte|contains", "value": ...}],
 "sort_by": "字段", "sort_order": "desc|asc", "limit": N,
 "fields": ["字段1", "字段2"]}
```

## AI 决策边界

| 维度 | 边界 |
|------|------|
| **能做** | NL→结构化查询翻译；跨实验差异分析；基于历史数据给出参数推荐（纯文本） |
| **不能做** | 执行查询（规则引擎执行）；修改历史记录；建议自动生效 |
| **人把关** | 不需要（只读，无破坏性） |
| **降级** | AI 不可用 → 模板匹配（识别"上次/所有/最高"等关键词） |

## MCP 工具

- `list_experiments`: 列出所有实验摘要
- `query_experiment(question)`: NL 查询
- `compare_experiments(id_a, id_b)`: 对比两个实验

## 关键类与方法

```
ExperimentQuery(log_dir, advisor)
  - _scan() → list[dict]          # 扫描 logs/summary_*.json
  - list_experiments(limit)       # 列表
  - get_experiment(exp_id)        # 按 ID 加载完整 JSON
  - query(question) → dict        # NL 查询入口
  - compare(id_a, id_b) → dict    # 实验对比 + AI 分析
  - suggest_params(task_type)     # 参数推荐
```
