# cp_16 · 推理测试助手 (InferenceRunner)

**文件**: `guardian/inference.py`, `scripts/infer_*.py`
**阶段**: 训练后
**核心目标**: 不用重复写推理代码——固定脚本 + 自动选 checkpoint

> **AI 决策边界**: 推荐 checkpoint / 推荐测试输入 / 解读结果（纯输出）。不生成代码。

---

## 为什么需要

每次训练完想快速看效果，都要：
1. 手写推理脚本（加载模型、预处理、跑 forward）
2. 手动指定 checkpoint 路径
3. 手动挑测试样本

F7 让这些自动化：选 best checkpoint → 自动检测任务类型 → 跑固定推理脚本 → 输出结构化结果。

## 固定脚本（不生成代码）

| 脚本 | 适用 |
|------|------|
| `scripts/infer_classification.py` | 分类：返回每张图的 top-5 预测 + 置信度 |
| `scripts/infer_detection.py` | 检测：返回 bbox + class + confidence |
| `scripts/infer_segmentation.py` | 分割：保存 mask PNG + per-class 置信度 |

脚本通过 subprocess 独立运行，与 guardian 进程隔离。

## AI 决策边界

| 维度 | 边界 |
|------|------|
| **能做** | 推荐用哪个 checkpoint 做推理；推荐测试输入样本；解读推理结果（纯文本） |
| **不能做** | 生成代码；自动执行推理结果修改模型 |
| **人把关** | checkpoint 推荐结果直接展示（可被覆盖）；脚本执行需用户触发 |
| **降级** | AI 不可用 → 用 best checkpoint + 随机采样输入 |

## MCP 工具

- `run_inference(checkpoint_epoch, task_type, inputs)`: 触发推理（训练后可写）

## 关键类与方法

```
InferenceRunner(config)
  - detect_task_type(model_fn) → str              # 规则推断
  - recommend_checkpoint(ckpt_analyzer, advisor) → int | None
  - recommend_inputs(data_dir, task_type, advisor, n_samples) → list[str]
  - run(checkpoint_path, task_type, inputs, output_dir) → dict
```
